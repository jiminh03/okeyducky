# 오키더키  
피지컬 AI 교감 메이트 로봇 '무키'를 통한 실시간 정서 케어와 안전 모니터링 플랫폼


## 프로젝트 소개

오키더키는 맞벌이 가정의 아이가 혼자 있는 시간에도 정서적으로 안정감 있게 생활할 수 있도록 지원하는 피지컬 AI 교감 메이트 로봇 서비스 입니다.  
실시간 AI 대화, 부모의 원격 소통, 자율 주행 기반 스마트 안심 케어 기능을 결합하여  
아이의 정서 케어와 안전 모니터링을 동시에 수행하는 통합 서비스입니다.

이 시스템은 프론트엔드 웹 서비스, 백엔드 서버, 로봇 임베디드 시스템, 상용 AI 모델 연동 서버로 구성됩니다.



## 팀 구성

### AI
* 실시간 대화 응답 생성 프롬프트 설계
* 전체 대화 로그 기반 감정 분석과 특이사항 추출
* 스마트 대화 리포트 자동 생성

### Backend
* 회원 인증과 로봇 계정 연동
* 스마트 리포트 생성 파이프라인
* WebSocket 기반 로봇 제어와 WebRTC 시그널링 구현

### Frontend
* 실시간 영상 스트리밍 UI
* AI 대화 리포트 피드 제공
* 부모 원격 소통과 텍스트 전달 UX 구성
* JWT 기반 인증 플로우

### Robot Embedded
* 로컬 STT와 발화 세그먼트 전송
* AI 객체 인식 기반 이족 보행
* TTS 재생 및 LED 상태 표시
* WebRTC 송신과 WebSocket 명령 처리

## 서비스 기획 배경

### 목표
아이의 정서 상태와 일상 대화를 지속적으로 이해하고  
부모가 함께하지 못하는 시간에도 아이의 마음을 안정적으로 돌보는 것을 목표로 합니다.

### Pain Point
* 부모는 아이가 혼자 있을 때 무엇을 하고 있는지 알기 어려움
* 아이는 외로움과 지루함을 느끼며 정서적 표현 상대가 부족함
* 기존 CCTV 기반 모니터링은 아이의 속마음과 감정 변화를 포착하지 못함

### 차별점
* 실시간 AI 대화로 아이에게 정서적 교감 제공
* 대화 로그 기반 스마트 리포트 자동 생성
* WebRTC 기반 초저지연 원격 소통
* 객체 인식 기반 자율 주행 안심 케어



## 주요 기능

### 실시간 AI 대화
* 아이 발화를 로컬 STT 기반 텍스트로 변환
* LLM이 공감 중심 응답 생성
* 오리 캐릭터 톤 TTS로 자연스럽게 출력
* 모든 대화 로그 자동 저장

### 스마트 대화 리포트
* 하루 동안의 대화 텍스트 자동 축적
* 요약, 긍정 단어, 특이사항 자동 분석
* 부모 앱으로 푸시 알림 발송
* 리포트 화면에서 원본 대화와 요약 확인 가능

### 실시간 안심 케어
* 객체 인식으로 아이를 식별하고 자율 추적
* WebRTC 기반 초저지연 영상 스트리밍 지원
* 음성 청취는 선택적으로 활성화 가능
* 집 안 위험 상황을 빠르게 확인

### 원격 소통 기능
* 부모가 앱에서 텍스트 입력
* 로봇이 캐릭터 음성으로 아이에게 전달
* 아이의 응답은 실시간 음성으로 부모에게 전달
* 부모 모드와 오리 모드 자연스러운 전환



## 시스템 흐름

### 실시간 AI 대화 흐름
* 아이 발화 감지
* 로컬 STT 수행
* 백엔드로 텍스트 전송
* LLM 응답 생성
* 로봇이 TTS로 재생
* 대화 로그 저장 후 비동기 리포트 분석

### 원격 소통 흐름
* 부모 앱에서 메시지 입력
* 백엔드가 TTS 요청
* 로봇이 음성 재생
* 아이 음성은 WebRTC로 부모에게 전달

### 스마트 안심 케어 흐름
* AI 객체 인식 기반 아이 위치 추적
* 이동 시 자율 주행
* 부모 실시간 보기 요청 시 WebRTC 연결
