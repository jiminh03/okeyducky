# 기능적 요구사항 명세서 (Functional Requirements Specification)
## 프로젝트: AI 교감 메이트 (수정안)

---

## 1. 기능적 사용자 요구사항 (Functional User Requirements)

### FR-U01: 공통 - 계정 및 로봇 관리
* **전제:** 외동을 전제로 서비스 구성
| ID | 요구사항 내용 |
| :--- | :--- |
| FR-U01.1 | (회원 가입): 부모는 이메일 주소(ID), 비밀번호, 서비스를 이용할 단일 아동의 이름(앱 내 호칭용) 등 최소한의 정보를 입력하여 회원 가입을 할 수 있다. |
| FR-U01.2 | (로그인): 부모는 가입 시 사용한 이메일 주소와 비밀번호를 통해 웹/앱 서비스에 로그인할 수 있다. |
| FR-U01.3 | (로그아웃): 부모는 서비스 이용을 마친 후 안전하게 로그아웃할 수 있다. |
| FR-U01.4 | (계정 관리): 부모는 '내 정보' 메뉴에서 자신의 비밀번호를 변경하거나 아이의 이름을 수정할 수 있다. |
| FR-U01.5 | (로봇 등록): 부모는 고유 시리얼 번호 또는 QR 코드를 통해, 자신의 계정에 **단 하나의** 오리 로봇만을 등록(연동)할 수 있다. |
| FR-U01.6 | (로봇 상태 확인): 부모는 웹/앱 메인 화면에서 웹 소켓 연결 상태 기반으로 내 로봇의 네트워크 연결 상태(예: 온라인, 오프라인)를 실시간으로 확인할 수 있다. |
| FR-U01.10 | (회원 탈퇴): 부모는 로봇 연동을 해제하고 회원 탈퇴를 통해 모든 정보를 삭제할 수 있다. |

### FR-U02: 부모 - 교감 및 성장 기록 확인 (기능 1 연계)
| ID | 요구사항 내용 |
| :--- | :--- |
| FR-U02.1 | (스마트 리포트 알림): 부모는 '스마트 리포트'(특이사항, 긍정 단어 감지 등)가 서버에서 자동으로 생성될 때마다 웹/앱을 통해 푸시 알림을 받을 수 있다. |
| FR-U02.2 | (리포트 피드 조회): 부모는 웹/앱의 리포트 메뉴에서, 생성된 '스마트 리포트'들을 최신순으로 모아볼 수 있다. |
| FR-U02.3 | (리포트 상세 내용 확인): 부모는 '스마트 리포트'를 선택하여, LLM이 요약한 '주요 대화 주제', '긍정 단어', '특이사항' 등 분석된 핵심 내용을 확인할 수 있다. |
| FR-U02.4 | (원본 대화 확인): 부모는 '스마트 리포트' 상세 화면 내에서, 요약의 근거가 된 '원본 대화' 텍스트를 (펼치기 기능 등을 통해) 함께 조회할 수 있다. |
| FR-U02.5 | (일일 리포트 접근): 부모는 달력(캘린더) 형태의 UI를 통해 특정 과거 날짜를 선택할 수 있다. |
| FR-U02.6 | (일일 리포트 조회): 부모가 특정 날짜를 선택하면, 그날 하루 동안 포착된 모든 '핵심 대화' 기록을 시간순으로 조회할 수 있다. |
| FR-U02.7 | (텍스트 전용 확인): 부모는 텍스트로 변환된 '원본 대화'만 확인할 수 있으며, 원본 '음성 파일'을 직접 재생하거나 다운로드할 수는 없다. |

### FR-U03: 부모 - 스마트 안심 케어 (기능 2 연계)
| ID | 요구사항 내용 |
| :--- | :--- |
| FR-U03.1 | (실시간 모니터링 시작): 부모는 웹/앱의 메인 화면이나 전용 메뉴를 통해 '실시간 보기' 기능을 즉시 시작할 수 있다. |
| FR-U03.2 | (실시간 영상 확인): 부모는 로봇의 카메라를 통해 아이가 있는 환경의 영상을 실시간(낮은 지연 시간)으로 확인할 수 있다. |
| FR-U03.3 | (실시간 음성 청취): 부모는 '실시간 보기' 중, 영상과 함께 아이 주변의 소리(음성)도 실시간으로 들을 수 있다. |
| FR-U03.4 | (음성 청취 제어): 부모는 아이의 프라이버시나 상황에 따라, '실시간 보기' 중 **음성 청취 기능(마이크)만 켜고 끌 수 있다.** |
| FR-U03.5 | (자율 주행 확인): 부모는 '실시간 보기' 중, 오리 로봇이 아이의 움직임을 자동으로 인식하여 따라다니는 모습(AI 객체 인식 및 자율 주행)을 확인할 수 있다. |
| FR-U03.6 | (모니터링 종료): 부모는 '실시간 보기'를 원할 때 언제든지 종료할 수 있다. |

### FR-U04: 부모 - 원격 소통 및 조작 (기능 3 연계)
| ID | 요구사항 내용 |
| :--- | :--- |
| FR-U04.1 | (실시간 소통 시작): 부모는 웹/앱에서 "라이브 톡" (Live Talk) 기능을 시작하여 로봇에 즉시 원격으로 접속할 수 있다. |
| FR-U04.2 | (소통 시작 알림): 부모가 '영상 통화'를 시작하면, 아이는 로봇의 알림음이나 LED 불빛을 통해 부모가 접속했음을 인지할 수 있다. |
| FR-U04.3 | (실시간 영상/음성 수신): 부모는 '영상 통화' 연결 동안, 아이의 모습과 목소리를 실시간으로 보고 들을 수 있다. |
| FR-U04.4 | (텍스트 메시지 전송): 부모는 '영상 통화' 화면의 전용 채팅창에 아이에게 전달할 메시지를 텍스트로 입력할 수 있다. |
| FR-U04.5 | (TTS 음성 변환): 부모가 텍스트를 입력하고 '전송'하면, 로봇은 즉시 해당 내용을 오리의 친근한 캐릭터 목소리로 아이에게 말해준다. |
| FR-U04.6 | (소통 종료): 부모는 원할 때 언제든지 '영상 통화'를 종료하고 '오리 모드'로 복귀시킬 수 있다. |

### FR-U05: 아이 - 로봇과 상호작용
| ID | 요구사항 내용 |
| :--- | :--- |
| FR-U05.1 | (자발적 대화): 아이는 언제든지 오리 로봇에게 자유롭게 자신의 감정이나 이야기를 말할 수 있다 (로봇은 LLM을 통해 친근한 '대화 상대'가 되어준다). |
| FR-U05.1.1 | (실시간 AI 대화): 아이가 로봇에게 말을 걸면, 로봇은 아이의 말을 텍스트로 변환(STT)하고, LLM의 답변을 받아 TTS로 응답함으로써 실시간 대화를 수행한다. |
| FR-U05.2 | (질문/답변 소통): 아이는 오리 로봇이 (부모로부터 받은) 질문을 오리의 목소리로 물어보면, 이에 대해 구두로 대답할 수 있다. |
| FR-U05.3 | (물리적 동반): 아이는 집 안에서 이동할 때, 오리 로봇이 자신을 인식하고 뒤따라오는 것을 경험할 수 있다. |
| FR-U05.5 | (실시간 하이브리드 대화): 아이는 '영상 통화' 중, 오리 로봇이 전달하는 부모의 메시지(TTS)를 듣고, 로봇의 카메라를 보며 자신의 목소리로 직접 대답할 수 있다. |
| FR-U05.6 | (휴식 시간 인지): 아이는 부모가 설정한 '방해 금지 시간대'에는 로봇이 말을 걸거나 움직이지 않고 **휴식 모드로 전환**되는 것을 경험할 수 있다. |

### FR-U06: 아이 및 부모 - 로봇 스케줄링
| ID | 요구사항 내용 |
| :--- | :--- |
| FR-U06.1 | (기본 동작 모드 - 동반): 아이는 평상시('방해 금지 시간' 외)에, 로봇이 자신을 시각적으로 인식하고 따라다니는 '동반 모드'를 기본으로 경험한다. |
| FR-U06.2 | (기본 동작 모드 - 대기): 아이가 시야에서 사라지거나 일정 시간 움직임이 없으면, 로봇은 지정된 대기 장소로 이동하여 '대기 모드'로 전환된다. |
| FR-U06.3 | (이벤트 - 부모 호출): 부모가 '영상 통화' 등을 사용하고 아이가 로봇 근처에 없을 경우, 아이는 로봇이 자신을 찾아와서 부모의 호출을 알리는 것을 경험한다. |
| FR-U06.4 | (스케줄 준수 - 방해 금지): 부모와 아이는, 부모가 설정한 '방해 금지 시간'이 되면 로봇이 모든 능동적인 움직임과 음성 알림을 중단하고 '조용한 대기 모드'를 유지하는 것을 인지한다. |
| FR-U06.5 | (원격 소통 인지): 아이는 오리 로봇의 알림(소리, LED 불빛 등)을 통해 부모가 '영상 통화'를 시작했음을 인지할 수 있다. |

## 2. 기능적 시스템 요구사항 (Functional System Requirements) - 최신화 버전

### FR-S01: 웹 서비스 - 프론트엔드 (Frontend / Client-side)
| ID | 요구사항 내용 |
| :--- | :--- |
| FR-S01.1 | (계정 UI): 이메일/비밀번호 기반의 회원가입, 로그인, 로그아웃, 비밀번호 변경, 회원 탈퇴 UI를 제공해야 한다. |
| FR-S01.7 | (모니터링 제어 UI): '실시간 보기' 화면 내에서, 수신되는 실시간 음성(마이크)을 켜고 끌 수 있는 **음소거(Mute) 버튼**을 제공해야 한다. |
| FR-S01.8 | (원격 소통 UI): '영상 통화' 실행 시, 비디오 플레이어와 텍스트 입력창, '전송' 버튼이 결합된 통합 UI를 제공해야 한다. |
| FR-S01.11 | (리포트 상세 UI): 리포트 상세 화면에서 '요약', '특이사항' 및 **'아이-로봇 간 원본 대화 텍스트'**(펼치기/접기 가능)를 제공해야 한다. |
| FR-S01.13 | (음성 파일 접근 금지): 리포트 조회 시 원본 음성 파일을 재생하거나 다운로드하는 기능을 일절 제공하지 않아야 한다. |

### FR-S02: 웹 서비스 - 백엔드 (Backend / Server-side)
| ID | 요구사항 내용 |
| :--- | :--- |
| FR-S02.9 | (WebRTC 시그널링): '실시간 보기' 및 '영상 통화' 시, 프론트엔드와 로봇 간의 WebRTC P2P 연결을 중계하기 위한 시그널링 서버 역할을 수행해야 한다. |
| FR-S02.10 | (명령어 전송): 프론트엔드로부터 받은 텍스트 메시지(TTS 요청)나 '영상 통화' 시작/종료 신호를, 소켓을 통해 즉시 해당 로봇에게 전송해야 한다. |
| FR-S02.12 | (대화 텍스트 수신) **(수정):** 로봇(FR-S04)으로부터 **STT 변환이 완료된 아이의 '대화 텍스트'**를 수신하는 엔드포인트를 제공해야 한다. |
| FR-S02.13 | (AI 연동 로직 - 대화 및 리포트): '대화 텍스트' 수신 시, 1) **(대화 응답)** 즉시 LLM을 호출하여 아이를 위한 '채팅 응답' 텍스트를 생성하고, 로봇에 전송한다. 2) **(리포트 분석)** 텍스트를 저장하고, 비동기적으로 LLM을 호출하여 '요약', '긍정 단어', '특이사항' 등의 리포트용 분석 결과를 생성해야 한다. |
| FR-S02.15 | (음성 파일 파기): 프라이버시 정책에 따라, 백엔드 서버는 원본 음성 파일을 수신하거나 저장하지 않아야 한다. |
| FR-S02.17 | (푸시 알림): '스마트 리포트'가 생성될 때마다, 푸시 알림 서비스와 연동하여 해당 사용자에게 알림을 전송해야 한다. |

### FR-S03: 오리 로봇 - 하드웨어 (Hardware)
| ID | 요구사항 내용 |
| :--- | :--- |
| FR-S03.2 | (마이크 어레이): 아이의 목소리를 명확하게 수음하고, 주변 소음 속에서도 음성을 식별할 수 있는 마이크 어레이를 탑재해야 한다. |
| FR-S03.5 | (메인 프로세서): 카메라 영상 처리, STT, 음성 데이터 실시간 인코딩, 서버 통신, 모터 제어 등을 동시에 수행할 수 있는 충분한 연산 능력을 갖춘 메인 프로세서를 탑재해야 한다. |

### FR-S04: 오리 로봇 - 제어 소프트웨어 (Embedded / Control S/W)
| ID | 요구사항 내용 |
| :--- | :--- |
| FR-S04.7 | (실시간 영상/음성 스트리밍): '부모 모드' 시작 명령 수신 시, 카메라와 마이크 데이터를 WebRTC 프로토콜을 통해 백엔드 시그널링 서버를 경유, 프론트엔드로 스트리밍해야 한다. |
| FR-S04.9 | (STT 수행 및 텍스트 전송) **(수정):** 포착된 음성 세그먼트를 **자체 STT 엔진 또는 클라우드 STT API**를 직접 호출하여 텍스트로 변환하고, 이 텍스트를 백엔드 서버(FR-S02.12)로 전송해야 한다. |
| FR-S04.13 | (TTS 엔진 연동) **(수정):** 백엔드로부터 텍스트(부모 메시지, LLM 응답)를 수신하면, 이를 음성으로 변환하여 스피커로 출력해야 한다. |

### FR-S05: 상용 AI 활용 및 프롬프트 엔지니어링
| ID | 요구사항 내용 |
| :--- | :--- |
| FR-S05.1 | (STT 모델) **(수정):** 로봇이 직접 호출하여 사용할 수 있도록, 한국어 아동의 음성 세그먼트를 높은 정확도로 텍스트 변환할 수 있는 상용 STT API를 선정해야 한다. |
| FR-S05.2 | (LLM 모델) **(수정):** 아이와의 '실시간 친근 대화' 응답 생성 및 대화 로그 기반 '요약', '키워드 추출', '특이사항 감지' 등 복합 작업을 수행할 수 있는 상용 LLM API를 선정해야 한다. |
| FR-S05.5.4 | (실시간 대화 프롬프트) **(신규):** 아이의 발화를 입력받아, **'7~11세 아이의 친근한 오리 친구'** 역할을 수행하며 정서적 교감을 나눌 수 있는 짧고 긍정적인 답변을 생성하는 프롬프트 템플릿을 설계해야 한다. |
